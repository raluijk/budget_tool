# BudgetTool

A personal budgeting tool that can be used to set up a budget and keep track of transactions. Transactions for a selected month can be compared to the budget and other transaction periods, along with a dashboard to get a more detailed overview of spending.

## Why

Setting up a budget can be a frustrating and time-consuming process. I wanted to create a budgeting tool that caters specifically to what I feel is valuable to have.

## Status

In development. Currently supports:
- Adding, updating, and deleting budget items
- Comparing transactions for a selected period to another transaction period
- Selecting multiple transaction periods with ease of scrolling through, making comparing a transaction period to any other transaction period very easy


## Planned
- Adding, updating, and deleting transaction items for any selected transaction period
- Adding a new transaction period if one does not exist yet
- Interactable dashboard that will display spending stats for a selectable number of months and for a selectable transaction period
- Accounts and authorization
- Adding transaction items by uploading a csv file
- Tool that can scan till slips, invoices, banking statements, etc, and generate a csv file or editable table that will read transactions from the document (Dependent on development of a Python script that will be created as a seperate project)


## Built with

ASP.NET Core, C#, PostgreSQL (Neon), vanilla JavaScript, HTML, CSS
